# Agent Lifecycle

1. **Bootstrap** — install the generic framework payload.
2. **Discover** — project-analyzer creates/recommends a project profile.
3. **Design** — agent-designer creates only specialists justified by durable gaps.
4. **Operate** — orchestrator routes tasks to the smallest sufficient family.
5. **Escalate** — NEEDS_USER_INPUT and CAPABILITY_GAP flow back through the orchestrator.
6. **Review** — non-trivial implementation receives independent review.
7. **Reassess** — re-run discovery after major stack/platform/security/architecture changes or repeated role failure.
8. **Retire** — remove project specialists that are no longer distinct or recurring.

Agent count is not a quality metric. Prefer fewer coherent roles over many near-duplicates.
